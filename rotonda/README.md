# Ротонда — сайт стоматологии

Одностраничный сайт, построенный вокруг одиннадцати клипов, снятых в Google Flow (Veo 3.1).
Статическая сборка на Vite и ванильных ES-модулях: ни React, ни какого-либо рантайма
компонентов, поэтому результат кладётся на любой хостинг как есть.

> **Клиника вымышленная.** Названия, люди, цены, адрес и телефон придуманы.
> Полный список того, что надо заменить перед публикацией, — в разделе
> [Что здесь выдумано](#что-здесь-выдумано) в конце файла. Прочитайте его до того,
> как показывать сайт заказчику.

### Как заменить ролик

Положите новые исходники в папку, поправьте `plates.map.json` (ключ — имя слота,
значение — имя файла из Flow) и прогоните энкодер:

```bash
python "C:\Users\Admin\.claude\skills\cinematic-video-site\scripts\encode_plates.py" --src "%USERPROFILE%\Downloads" --out public/video --map plates.map.json
```

Скрипт сам делает mp4, webm и постер, и удаляет webm, если тот получился тяжелее mp4
(на зернистом и мелкодетальном материале VP9 проигрывает x264, а webm в `<source>` идёт
первым — браузер скачал бы файл побольше).

Два плейта входа во двор именно так и потеряли webm: листва и рябь солнца через тополя
дают слишком много высокочастотной детали. Они пережаты отдельно с `crf 31`:

```bash
ffmpeg -y -i "вход.mp4" -an -vf "scale='min(1280,iw)':-2" -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 31 -preset slow -movflags +faststart -g 48 public/video/place-entrance.mp4
```

### Вес

| | Бюджет | Факт |
|---|---|---|
| Первый экран | < 3 МБ | **0,69 МБ** |
| Герой отдельно | < 2,5 МБ | 478 КБ (webm) |
| Самый тяжёлый плейт ниже сгиба | < 3 МБ | 1,6 МБ (`place-entrance-v`) |
| Декоративный оверлей | < 500 КБ | 30 КБ (`texture-glass`) |
| Все плейты | < 20 МБ | **6,78 МБ** |
| JS | < 200 КБ / 70 КБ gzip | 143 КБ / **53,9 КБ gzip** |

Всё, кроме героя, грузится лениво: `<source data-src>` подставляется в `src` только когда
`IntersectionObserver` видит элемент. Горизонтальный и вертикальный плейты входа взаимно
исключают друг друга через `display: none`, так что десктоп не качает вертикальный, а
мобильный — горизонтальный.

Three.js намеренно не подключён. Шейдеру здесь нечего делать, а полмегабайта на телефон
он бы стоил.

## Перекраска

Всё живёт в `src/css/tokens.css`. Значения сняты пипеткой с кадров, а не подобраны
в палитре: `--paper` — усреднённое терраццо и стены, `--ink` — рукоятки инструментов,
`--sage` — матовое стекло перегородки. Дерево в интерфейс не заходит вообще: это материал,
он живёт в кадрах.

Достаточно поменять четыре переменные, остальное подтянется:

| Переменная | Что это | Значение |
|---|---|---|
| `--paper` | Земля светлых секций | `#F2EFE8` |
| `--ink` | Основной текст | `#1C1F1B` |
| `--sage` | Единственный акцент: кнопки, ссылки, активная строка шкалы | `#3F5742` |
| `--night` | Земля тёмных секций | `#1E211E` |

Если меняете их — проверьте контраст заново. Три производных токена подобраны под
конкретную землю: `--ink-soft` даёт 5,6:1, `--ink-faint` 4,65:1, `--night-soft` 6,1:1.
Шрифты (`--serif`, `--sans`) — Source Serif 4 и Onest, оба с нормальной кириллицей,
подключены с Google Fonts в `index.html`.

## Как сайт себя ведёт

**Структура.** Пять роликов сняты движением вперёд в одном направлении, поэтому позиция
скролла — это буквально позиция в клинике. Шкала слева показывает комнату и тайм-код,
собранный из реального хронометража: пять плейтов по восемь секунд, отсюда `00:00`–`00:40`.
Цифры не придуманы под дизайн, их можно вывести из самого материала.

**От 900 px.** Блок «Приём» закрепляется на весь экран: слева бумажная колонка с текстом
и шкалой, справа окно в клинику. Кадры сменяются кроссфейдом по прогрессу скролла,
декодирует только активный. Шапка инвертируется в тёмную над секциями `.craft` и `.foot`.

**До 900 px.** Закрепление выключается целиком, блок становится обычной колонкой:
кадр 16:9, под ним текст. Шкала скрыта. Занавес героя переключается с левостороннего
на нижний, потому что копия идёт во всю ширину. Ниже 640 px прячется подпись «Листайте».

**Reduced motion.** Плавный скролл, закрепление и все анимации выключаются. Ни один ролик
не играет — вместо них постеры. Тумблер «Видео» в шапке при этом остаётся доступным:
человек может включить движение обратно сам, решение за него не принимается.
Все состояния покоя в CSS — это финальные состояния, поэтому при выключенных анимациях,
при отвалившемся бандле и при выключенном JS ничего не застревает на полпути.

**Тумблер «Видео».** Проходит через один контроллер (`src/js/plates.js`), поэтому достаёт
до всех роликов, включая героя — тот играет вне ленивых наблюдателей и обычно
про него забывают. Проверено замером: под reduced motion до клика играет 0 роликов,
после клика — герой; в обычном режиме наоборот.

**Форма.** Проверка на клиенте: имя от двух символов, телефон ровно 11 цифр, ошибка
показывается у поля, а не сводкой сверху, поле проверяется по `blur`. **Никуда ничего
не отправляется** — обработчик показывает подтверждение и очищает поля. Подключите
свой бэкенд в `src/js/form.js`.

## Что стоит знать про сами ролики

- `cta-doorway` пришёл мягким по фокусу — единственный плейт, промахнувшийся мимо ТЗ
  (просил глубокий фокус). На финальном экране расфокус читается как выдох и уход
  в белый, поэтому оставлен. Если будете перегенерировать — добавьте `f/8, deep focus,
  everything sharp` и уберите `shallow`.
- На корпусе микроскопа в `room-03-microscope` Veo впечатал слово, похожее на бренд.
  При `object-fit: cover` в закреплённой сцене оно обрезается и в кадр не попадает,
  но при смене вёрстки проверьте заново.
- На стеклянной двери в обоих плейтах входа видны листы объявлений. Текст нечитаемый,
  но это именно та «вывеска», которую промпт запрещал.
- Герой снят проездом вперёд и **не зацикливается сам по себе** — последний кадр
  на несколько метров дальше первого. Луп собран из двух копий одного файла, которые
  перекрёстно затухают за 0,85 с (браузер качает файл один раз). Если замените герой
  другим проездом — всё продолжит работать; если поставите статичный зацикленный кадр,
  вторую копию можно убрать из разметки.
