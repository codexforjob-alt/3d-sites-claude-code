# Bright Smile Studio

Демонстрационный одностраничник вымышленной стоматологической клиники. Все данные —
название, адрес, телефон, цены, отзывы, статистика — придуманы. Форма записи ничего
не отправляет. Страница закрыта от индексации (`robots: noindex`).

## Стек

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (токены палитры — CSS-переменные в `globals.css`)
- GSAP + ScrollTrigger — скролл-анимации: параллакс в hero и «Атмосфере клиники»,
  батч-ревилы, пиннинг + scrub в секции «Процесс лечения»
- Framer Motion — микро-интеракции: hover карточек, кнопки, мобильное меню,
  карусель отзывов, состояния формы

**Без 3D.** Нет Three.js / R3F / Babylon / WebGL и объёмных трансформаций.
Вся графика — плоские 2D SVG-иконки, анимации — 2D transform + opacity.

## Видео

Пять фоновых роликов в `public/videos` (mp4 + webm) с постерами в `public/posters`.
Исходники перекодированы в 1280–1600 px, без звука, `faststart`; общий вес ~7,5 МБ.

| Файл | Где используется |
|---|---|
| `hero-waves` | Hero, полноэкранный фон |
| `smile-transform` | «Почему мы», карточка результата |
| `clinic-ambience` | Секция «Атмосфера клиники» |
| `tooth-loop` | «Процесс лечения», круглая заставка |
| `cta-smile` | Панель записи, фактура под брендовым тоном |

Компонент `VideoBackground` монтирует `<source>` только когда секция подходит к
вьюпорту, показывает постер до `canplay`, ставит на паузу скрытую вкладку и вовсе
не грузит видео при уменьшенном движении.

## Доступность

- `prefers-reduced-motion` отключает параллакс, пиннинг, автопрокрутку отзывов и видео
- Кнопка паузы в шапке даёт тот же режим вручную (WCAG 2.2.2)
- Видимый фокус, skip-link, aria-label у иконочных кнопок, ошибки формы рядом с полями
- Контент виден без JS: ревил-анимации включаются только классом `js-motion`

## Разработка

```bash
npm install
npm run dev
```
